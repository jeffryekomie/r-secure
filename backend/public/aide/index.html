Centre d'aide

Activer l'application

Après votre paiement, un code d'activation s'affiche. Ouvrez l'application, entrez ce code puis créez votre compte. Le code ne fonctionne que sur un seul téléphone.

Voir les appareils connectés

Connectez votre téléphone au wifi du routeur (pas aux données mobiles), puis ouvrez l'application.

Déconnecter, bloquer ou débloquer un appareil

Ouvrez l'appareil dans la liste et choisissez l'action voulue.

Problème de connexion au routeur

Vérifiez que vous êtes bien sur le wifi du routeur, puis réessayez.

Parrainage

Touchez le bouton cadeau 🎁 dans l'application pour obtenir votre lien et suivre vos gains.

Besoin d'aide ?

Contactez votre vendeur RTL.
